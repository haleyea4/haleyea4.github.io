Privacy Policy

Last updated: November 7, 2026

This application is a personal project operated by one individual for use in a single household. It connects the owner’s own Google Nest devices to the owner’s own Home Assistant system through Google’s Smart Device Management API.

Data accessed

With the owner’s authorization, the application accesses data from the owner’s own Nest devices, such as camera and thermostat status and events, solely to display and control those devices inside the owner’s Home Assistant.

Data use and sharing

Device data is processed only within the owner’s home systems. It is not sold, rented, shared with third parties, or used for advertising. No other person’s devices or data are accessed.

Data retention and revocation

Access tokens are stored only in the owner’s Home Assistant instance. The owner can revoke the application’s access at any time at https://myaccount.google.com/permissions, which immediately ends all data access.
